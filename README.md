# Multi-Asset Quantitative Signal Research

**For:** Barclays — Markets Quantitative Analyst Summer Internship Program 2028, New York (JR-0000139049)
**Author:** Bhupesh Chandra Dimri
**Stack:** Python 3, pandas, scikit-learn, matplotlib

## One-liner
A walk-forward, transaction-cost-aware signal research project across six synthetic
multi-asset instruments (Equities, Credit, Rates, FX, Municipals, Securitized
Products): momentum, mean-reversion, volatility and carry signals, four models,
honest out-of-sample backtesting.

## ⚠️ Synthetic data — read first
All market data in this project is **synthetic**, generated by `src/data_gen.py`
with a known, auditable process (small persistent momentum component plus
volatility clustering). **Nothing here is live-market performance** and no
result should be read as a claim about real Barclays desks or real securities.

## How to run
```bash
python run_all.py            # data -> features -> backtest -> charts + reports/metrics.json
python -m tests.test_all     # test suite (prints a runtime "N passed" line)
```

## Headline results (out-of-sample, 940 days, net of 5bp costs)
| Model | Hit rate | Sharpe | Total return | Max drawdown |
|---|---|---|---|---|
| Momentum rule | 50.2% | **0.71** | +11.0% | -5.1% |
| Linear regression | **51.1%** | 0.59 | +9.4% | -5.4% |
| Logistic regression | 50.9% | 0.43 | +7.1% | -8.1% |
| Random forest | 49.9% | -1.28 | -18.3% | -19.4% |

**Honest finding:** the random forest memorised the training data (68.3%
in-sample accuracy) and lost money out of sample — high turnover (25.8%)
plus noise-fitting. The simple momentum rule won. That is the point of the
project: in noisy markets, interpretability and turnover discipline beat
model complexity. Momentum also only works in low-volatility regimes
(Sharpe 1.70 low-vol vs -0.24 high-vol for the momentum rule).
